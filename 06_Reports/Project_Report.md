# Project Report

## Project Title
Factory Reallocation & Shipping Optimization Recommendation System

## Organization
Nassau Candy Distributor

## Objective
The project identifies better factory assignments for customer orders by analyzing shipping distances, customer locations, factory locations, sales, profit, and regional information.

## Key Results

- Total Recommendations: 6,967
- Average Distance Saved: 1,742 KM
- Average Distance Improvement: 66.43%
- Recommendation Coverage: 68.34%
- Scenario Confidence Score: 66.43%
- Profit Impact Stability: Stable

## Machine Learning

The project evaluated:
- Linear Regression
- Random Forest
- Gradient Boosting
- Clustering

Gradient Boosting was selected as the best-performing model based on the evaluated MAE and RMSE results.

## Optimization

The optimization process identifies orders where changing the factory can reduce shipping distance and provides recommended factory assignments.

## Dashboard

The project includes:
- Power BI dashboard
- Streamlit interactive dashboard
- Factory-wise distance analysis
- Region-wise sales analysis
- Ship mode distribution
- Product-level recommendations
