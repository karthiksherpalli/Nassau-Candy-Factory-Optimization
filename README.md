# Nassau Candy Factory Reallocation & Shipping Optimization

## 📌 Project Overview

The **Nassau Candy Factory Reallocation & Shipping Optimization Recommendation System** is a data-driven project designed to identify better factory assignments for customer orders.

The system analyzes customer locations, factory locations, shipping distances, sales, units, gross profit, ship mode, products, and regional information to identify alternative factory assignments that can reduce transportation distance and improve logistics efficiency.

The project combines **Python, Machine Learning, SQL, Power BI, Geographic Distance Analysis, Scenario Simulation, Optimization, and Streamlit** to provide data-driven factory reallocation recommendations.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze current factory-to-customer shipping distances.
- Identify suitable alternative factories for customer orders.
- Calculate potential distance savings.
- Measure distance improvement percentage.
- Recommend better factory assignments.
- Analyze sales and profit across factories and regions.
- Analyze product and shipping-mode performance.
- Support logistics and supply-chain decision making.
- Provide interactive dashboards for exploring recommendations.
